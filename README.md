## 🎨 Portfolio Features & Highlights

This portfolio is built completely from scratch using **pure Vanilla HTML, CSS, and JavaScript** with zero external frameworks or heavy dependencies:

- 🌌 **Dual Time-Lapse Video Backgrounds:** Seamless crossfade between night starscape and daylight sky.
- ✨ **Constellation Particle System:** Physics-based starfield with interactive magnetic mouse breeze.
- 🎵 **Ambient Audio Player:** Custom player with animated equalizer bars and persistent controls.
- 📱 **Adaptive Responsive Design:** Carefully crafted layouts for phones, tablets, and wide monitors.
- 🌓 **Dynamic Theme Switching:** Instant light and dark mode with persistent user preference.
- ⚡ **Lightweight & High Performance:** Fast loading times with no framework overhead.
